# Changelog

All notable changes to andtls will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [0.1.0] — 2026-08-22

### Added

- Live USB device monitoring with 1-second polling
- Device table with status, serial, model, battery, transport ID
- Deep device inspector (hardware, OS, network, battery, storage)
- Quick screenshot capture (`s` key)
- Wireless ADB toggle (`w` key)
- Reboot menu — normal, recovery, bootloader (`b` key)
- Interactive help modal (`?` key)
- Empty state with troubleshooting guidance
- Debian packaging support
- Build and install scripts
- udev rule generator for Linux USB devices
- Log parser and metrics collector (Perl scripts)
